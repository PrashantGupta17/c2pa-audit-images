# Privacy Policy

Last updated: 2026-06-29

This page describes how the C2PA Durability Audit research project (the "Project") handles data.

## Information we collect

The Project does not collect personal information from any third party. The only data handled by the Project is:

- Test images generated by the researcher specifically for this study.
- Post-upload media URLs and metadata returned by platform APIs after the researcher's own test posts are uploaded.
- C2PA manifest verification results and watermark detection results computed locally from downloaded test media.

The Project does NOT:

- Collect data about users of any platform.
- Read, store, or analyze posts or media from any account other than the researcher's own research-dedicated accounts.
- Share data with third parties.

## Authentication tokens

API tokens issued by platforms to the researcher are stored locally on the researcher's machine in plaintext credentials files for the duration of the study and are deleted after the study concludes.

## Data retention

Test content (images, metadata, c2patool output) is retained for the duration of the study to support reproducibility of findings, including any post-publication audits. After the study is published, the researcher may delete test content from the platforms via API where supported.

## No tracking

This page itself does not use cookies, analytics, or any tracking technology.

## Contact

For questions about data handling, contact via the GitHub profile of the repository owner.
